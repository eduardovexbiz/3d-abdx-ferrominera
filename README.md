# Protector antirrobo – Válvula de control ABDX (Ferrominera)

Modelo 3D interactivo de los protectores antirrobo para la válvula de control de freno ABDX de los vagones de carga.

**Ver el modelo:** https://eduardovexbiz.github.io/3d-abdx-ferrominera/

- CP-01 · Porción de servicio: 230 × 330 × 270 mm, soldado al soporte, con tapa.
- CP-02 · Porción de emergencia: 230 (+50 hasta el soporte) × 200 × 270 mm, esquinas exteriores redondeadas, soldado al soporte, con tapa.
- Plancha de acero 4 mm (A36 / Q235B). Fondo ranurado para escape de aire y drenaje.
